# Storylines — Brain² tab video (YouTube)

**The one thing:** ask ClickUp Brain² about the task you're looking at, from the side panel, without leaving the page.
**Remember after:** "I can ask Brain about this bug right here, and it already knows which task I mean."
**Spine:** one person, one bug. Task "Pay button overlaps the order summary" on a staging checkout page; the question
"What's left before we can close this bug?" travels from hook to payoff.
**Facts on screen (from CHANGELOG/README):** task offered as a one-click chip (detected from the page); + adds Deep
Research, tasks and docs, files; Skills or `/`; model picker (Brain² or other models ClickUp offers) with thinking
effort; answer streams, then ClickUp formatting, task links with status colour; follow-ups; Open in ClickUp.
Never imply ClickUp built or endorses the extension.

---

## A — "Before the release" (recommended)

**Device:** a moment in someone's day. **Form:** one continuous take (the camera never cuts; it pushes and pulls).

A QA lead on the staging checkout page, the Pay button visibly sitting on top of the order summary, and a Slack-style
note: "Can we close the checkout bug before release?". The old way churns for two seconds (ClickUp tab, search, comments,
scrolling) then collapses back into the one page, where the side panel slides in and Brain answers right beside the bug.

- **First 2 s:** the checkout page fills the frame at 1.6×, the cursor hovers the overlapping Pay button; a note drops
  in top-right: "Close the checkout bug before release?" — 4:52 pm.
- **Beats:** hook (bug + deadline) → tension (tabs pile up, comments scroll, clock ticks) → reveal (panel slides in on
  the same page, "Brain² tab") → proof: click the task chip · ask · watch it stream · task link turns status colour →
  payoff (the full answer: Safari check, Sara's review, "Omar saw it on the cart page") → quick extras (+ docs & files,
  Skills, model) → claim → end card.
- **Look:** the real checkout page and the real panel on white, brand purple #7b68ee rationed to the composer ring and
  the end card; system UI type; one material: the panel's soft shadow lifting off the page.
- **Sound:** Kokoro `af_heart` voiceover as in the store promo, no music.

## B — "Where did that answer come from?"

**Device:** the result first. **Form:** object-to-object chain.

Opens on Brain's finished answer, huge and legible, then pulls back to reveal it's sitting in a side panel next to the
bug. Then each piece of the answer is traced back to what made it: the task link becomes the chip, the chip becomes the
page URL it was detected from, "checkout.css" becomes the doc added with +, "Brain²" becomes the model menu.

- **First 2 s:** full-frame text "**Pay button overlaps the order summary** is in review. Before it can close:" with
  the orange status dot, the bullets typing on.
- **Beats:** hook (answer) → pull back to the panel beside the page → "how did it know?" chain: link → chip → page URL ·
  "+" → tasks, docs, files · Skills · model + effort → back to the full answer → Open in ClickUp → claim → end card.
- **Look:** starts type-only on white (the answer is the hero), lands in the real UI; purple only on the thread
  connecting each piece back to its source.
- **Sound:** Kokoro voiceover, no music.

## C — "Inside the composer" (bold)

**Device:** the object is the explanation. **Form:** one frame that rebuilds / an endless zoom.

The Brain composer box is blown up to fill 1920×1080 and never leaves. Each control is a door: the camera dives into
"+" and a desk of tasks, docs and files spreads out and drops into the box; into "/ Skills" and skills fan out; into the
model button and it flips Brain² → other models with a thinking-effort dial. Then Send, and the answer pours out of the
box until it fills the frame; pull back all the way to the panel, beside the checkout page.

- **First 2 s:** the composer's purple ring fills the frame edge to edge, the placeholder "Ask, search, or create…",
  and the task chip "Pay button overlaps the order summary" pops in.
- **Beats:** hook (giant composer + chip) → dive "+" → dive Skills → dive model → type the question → Send → answer
  floods the frame (payoff) → pull back to the panel on the page → claim → end card.
- **Look:** the composer's own white, grey chips and purple ring at 4–6× scale; no other ground until the final pull-back.
- **Sound:** Kokoro voiceover, no music.
