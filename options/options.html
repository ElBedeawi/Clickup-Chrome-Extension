Video & Screenshot Uploader for ClickUp

by Wagih Elbedeawi

Paste your ClickUp personal API token. Get it from ClickUp → Settings → Apps (it starts with pk_). It is stored only in this browser.

Saved token

Removes the token from this browser — the extension stops working until you add one again. To also invalidate the token itself, regenerate it in ClickUp → Settings → Apps.
